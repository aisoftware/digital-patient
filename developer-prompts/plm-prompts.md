# Product Lifecycle Management Prompts

## Device Model Management

### Model Packs
- Define device configurations in structured format
- Include firmware versions and compatibility matrices
- Document safety parameters and limits
- Version all configuration changes

### Packaging Pipeline
- Automate build and validation processes
- Run quality assurance checks
- Generate deployment packages
- Create rollback packages for safety

### Version Manifests
- Track all deployed configurations
- Maintain version history and changelog
- Document dependencies between versions
- Link to regulatory approvals

## Change Control

### Process Steps
1. Development and local testing
2. Peer review and approval
3. QA validation in test environment
4. Regulatory review (if required)
5. Production deployment
6. Post-deployment monitoring

### Documentation
- Document rationale for all changes
- Track regulatory submissions
- Maintain traceability matrix
- Archive all versions

## Compliance

### Regulatory Requirements
- FDA 21 CFR Part 820 (Quality System Regulation)
- ISO 13485 (Medical Devices QMS)
- IEC 62304 (Medical Device Software)
- HIPAA compliance for data handling

### Best Practices
- Implement change control workflows
- Maintain audit trails
- Conduct risk assessments for changes
- Document all decisions and approvals
