Digital Patient Platform

A comprehensive healthcare data management system for managing patient information, provider interactions, and medical device lifecycle.

Project Structure:
- /src/database: Database schemas and SQL files
- /src/webapi: REST API with HL7/EDI integration
- /src/queue: Message queue processing
- /src/mobile: React Native mobile application
- /src/portal: Next.js provider portal
- /src/plm: Product lifecycle management for medical devices
- /docs: Technical documentation

For more information, see the documentation in the /docs directory.
